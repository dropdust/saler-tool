# Quickstart: 通用销售获客工具（本地桌面版）

**Feature**: `001-sales-tool` | **Date**: 2026-10-10

本文件是**验证与运行指南**：如何把应用跑起来，并按用户故事逐条验证规格是否被满足。
技术选型与实现细节见 [plan.md](plan.md) / [research.md](research.md)；数据形状见 [data-model.md](data-model.md) 与 [contracts/](contracts/)。

## 1. 环境前提

**开发机**
- Python ≥ 3.12（建议 3.13）+ `uv`；Node ≥ 20 + `pnpm`（前端构建）
- 目标平台基线：Windows 10/11（WebView2 Evergreen，系统自带）；macOS 12+（WKWebView）；Linux 以 **Ubuntu 22.04+** 为最低验证基线（WebKitGTK ≥ 2.36 / 4.1，libsoup3）
- 打包工具：PyInstaller（三平台）；发布安装器：Inno Setup/NSIS（Windows）、DMG（macOS）、AppImage/deb（Linux）

**运行应用需要用户自备（对应规格 Assumptions）**
- 大模型服务密钥（首批支持清单见 research.md；应用内可配置多个、可测试连通）
- 检索渠道密钥（搜索引擎/检索服务；支持配置多个渠道与优先级）
- 邮箱发信凭证（发信服务器、账号、授权码）；可选：短信服务商凭证
- 可选：本机网络代理（访问部分海外站点与检索服务需要）

## 2. 本地开发运行

```bash
# 1) 后端（本地 API + 任务引擎，仅绑定 127.0.0.1）
cd backend && uv sync
uv run uvicorn saler.api.main:app --reload --port 8620

# 2) 前端（Vite dev server）
cd frontend && pnpm install && pnpm dev        # 默认 http://localhost:5173

# 3) 桌面壳（pywebview 原生窗口；开发期可指向 Vite dev URL）
uv run python -m saler.desktop
```

## 3. 构建与打包（每平台产物）

```bash
# 前端构建产物（随包内嵌）
cd frontend && pnpm build                       # 输出 frontend/dist

# 后端 + 桌面壳：PyInstaller 单目录形态（约定：--onedir，不用 --onefile）
pyinstaller packaging/saler.spec                # 产物 dist/SalerTool/
# 再套安装器：
#   Windows → Inno Setup/NSIS：SalerTool-<ver>-setup.exe
#   macOS   → .app → 签名+公证 → DMG（流程见 plan.md）
#   Linux   → AppImage 或 .deb
```

**冻结包冒烟（必做）**：每个平台在真实安装产物上重跑 S1 / S6 / S10。冻结后才会暴露 `gi`/uvicorn 导入类问题（陷阱清单见 plan.md）。

## 4. 端到端验证场景

每个场景以"可观察行为"验收，不依赖实现细节；括号内为对应需求与成功标准。

### S1 首次启动与数据主权（US3 / FR-002/003/033）
前置：全新安装。
步骤：① 指定数据目录；② 断网启动；③ 完全离线状态下手工创建 1 个产品线节点与数条种子；④ 观察首启主题（应默认浅色），用页头主题开关切到深色并确认全界面即时切换（002-frontend-theme 增量）。
预期：离线可用；数据文件位于所选目录；无任何强制云账号引导；首启默认 light，主题开关全局一步可达、切换即时生效（002 quickstart T1/T2）。

### S2 大模型配置与连通测试（US3 / FR-030/031）
前置：持有一个大模型密钥。
步骤：录入配置 → 测试；随后故意填入错误密钥再测试。
预期：分别显示"可用（含模型信息）"与"可操作的失败原因"；密钥在界面、日志与导出物中始终脱敏。

### S3 种子知识库：手工 + AI 扩充 + 翻译 + 审核（US1 / FR-007~012 / SC-001）
前置：S2 通过。
步骤：① 创建产品线/客户角色/市场节点并手工加约 10 条种子；② 输入行业描述，让大模型扩充（指定数量，产出一律为中文母版候选）；③ 在待审核清单中采纳一半、拒绝一半；④ 勾选已采纳的中文种子执行目标语言翻译（AI 翻译，同样先审后用）。
预期：AI 候选全部进入"待审核"，未审核项不进入执行队列；采纳项带分类/优先级/来源落库；图谱与种子统计可见；1 小时内可达到 ≥100 条可执行种子。

### S4 图谱可视化与产量排序（US1 / FR-015/017/018）
前置：S3 数据；额外用模板文件批量导入一批历史种子。
步骤：打开图谱视图，切换"结构/实体"两个视图，按市场与批次筛选；按产量排序种子列表；在种子列表按语言筛选并与其他条件组合（003 增量）。
预期：颜色/大小反映覆盖率与产量，能识别空白市场与零产出种子；导入报告列出新增/重复条数。

### S5 种子导出与外部回灌（FR-016）
前置：已有种子库。
步骤：① 导出执行清单（txt 与 csv 各一次）；② 用一份 `harvest_v1` 示例回灌文件执行导入（格式见 contracts/data-exchange.md）。
预期：回灌报告返回 matched/unmatched/new_domains 等统计；命中种子的状态转 `done` 且产量更新；未匹配查询进入待处理清单而非丢失。

### S6 挖掘任务与断点续跑（US2 / FR-019~026 / SC-003）
前置：配置好检索渠道（004 增量：官方 API 或免密钥网页渠道均可——免密钥渠道"尽力而为、失败自动切换"，合规责任自担）；选定一批种子。
步骤：① 启动挖掘任务并观察进度与日志；② 任务运行中强制退出应用；③ 重新启动并恢复任务；④ 模拟断网片刻再恢复。
预期：恢复后不重复抓取已完成目标（重复记录为 0）；断网时任务暂停并提示，网络恢复后可继续；进度与统计始终正确。

### S7 联系方式提取、去重、排除与导出（US2 / FR-020~023/027/028）
前置：S6 产出若干公司。
步骤：① 抽查公司详情（邮箱/电话/WhatsApp/Facebook、分类、来源页面）；② 新建一条排除规则并对存量线索应用；③ 人工补录一条联系方式；④ 导出表格（含被排除清单与统计 Sheet）。
预期：同公司同值联系方式仅一条；被排除对象移出买家列表单独存放且不进入营销人群；导出字段完整；异常格式被标"疑似无效"。

### S8 营销内容：母版 → 多语言 → 审校 → 发布（US4 / FR-034~039 / SC-008）
前置：S2 通过。
步骤：① 新建邮件主题，用大模型辅助起草中文母版（含变量占位）；② 一次生成 ≥3 个目标语言版本；③ 预览渲染效果；④ 修改正文后查看/恢复历史版本；⑤ 审核并发布中文与英文版本。
预期：语言版本带"母版 → 版本"血缘；未发布版本在计划中不可选；预览展示变量替换并高亮缺失变量；历史版本可恢复（恢复=生成新版本号）。

### S9 通道配置与测试发送（US5 / FR-040~044 / SC-009）
前置：邮箱凭证（可选短信凭证）。
步骤：① 配置邮箱通道并测试连通；② 发送测试邮件给自己；③ 设置每日上限；④ 再配置第二个发件邮箱。
预期：从录入到测试发送成功 ≤10 分钟；限额与用量可见；凭证明文不出现在任何界面/日志/导出中。

### S10 营销计划全链路（US6 / FR-046~054 / SC-002/004）
前置：S7 线索 + S8 已发布内容 + S9 通道。
步骤：① 创建计划圈定人群，查看影响范围预估；② 试发 2 封（发给自己/同事）；③ 正式启动；④ 中途暂停再恢复；⑤ 完成后查看并导出台账；⑥ 对同一人群再建一个计划；⑦ 将一个邮箱加入退订名单后重跑。
预期：预估给出客户数/条数/语言分布/预计时长；进度实时、失败可重试；第二次计划默认跳过已发送客户（重复发送为 0）；退订对象在所有计划中被排除。

### S11 备份、恢复与迁移（US3 / FR-004 / SC-005）
步骤：① 生成备份归档；② 在另一台设备（或清空后的环境）校验并恢复。
预期：种子/线索/内容/通道/台账/设置完整一致；损坏或版本不符的备份被拒绝且不影响现有数据。

### S12 兜底与多平台冒烟（SC-006/010）
步骤：① 在未配置大模型的环境完成"手工建模 → 挖掘 → 内容 → 发送"全链路；② 在 Windows/macOS/Linux 安装产物上各跑 S1/S6/S10。
预期：无 AI 环境全链路可用（AI 入口提示"需配置模型"）；三平台功能一致。

## 5. 常见问题排查

| 现象 | 排查方向 |
|---|---|
| Linux 报 `GLib.GError: Failed to load web view` | 安装 `gir1.2-webkit2-4.1`（或 4.0）+ `python3-gi`；确认发行版 ≥ Ubuntu 22.04 |
| 冻结包启动即退 / 导入缺失 | 重跑"冻结包冒烟"；检查 PyInstaller hiddenimports（uvicorn/fastapi/gi）与 `--add-data` 前端产物 |
| 检索渠道被风控/限流 | 按规格 Edge Cases：自动降速或切换备用渠道；检查渠道密钥与代理配置 |
| SMTP 测试失败 | 检查是否为授权码（而非登录密码）、端口与加密方式、发件域策略 |
| 代理环境下本地 API 连不上 | 回环地址需绕过系统代理（实现层处理 `no_proxy`） |
